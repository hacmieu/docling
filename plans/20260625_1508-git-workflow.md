# Plan Entry - Push and Merge

## Push plan

1. Ensure clean or intended staged changes.
2. If this is a feature/fix, create branch from `main`.
3. Push with upstream: `git push -u origin <branch-name>`.
4. Open PR to merge into `main`.

## Merge-in plan for new code

1. Update local `main`:
   - `git checkout main`
   - `git pull origin main`
2. Move to working branch:
   - `git checkout <your-branch>`
3. Bring latest `main` into your branch (recommended rebase):
   - `git rebase main`
4. Resolve conflicts, run tests, push branch, then merge via PR.
