# Plan Entry - MVP Usage Plan

## How to run

- Basic:
  - `uv run python scripts/folder_to_sqlite_mvp.py --input-dir <folder>`
- Include subdirectories:
  - `uv run python scripts/folder_to_sqlite_mvp.py --input-dir <folder> --recursive`
- Enable OCR for scanned PDFs:
  - `uv run python scripts/folder_to_sqlite_mvp.py --input-dir <folder> --enable-ocr`
- Aggressive OCR mode:
  - `uv run python scripts/folder_to_sqlite_mvp.py --input-dir <folder> --enable-ocr --force-full-page-ocr`

## Evaluation follow-up

- Compare markdown quality between OCR modes by querying `documents.markdown`.
- Compare structured extraction consistency by diffing `documents.doc_json`.
